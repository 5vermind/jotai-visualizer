# Jotai Visualizer v0.1.0

The first open-source preview turns Jotai runtime state into an embedded, searchable graph
of atoms, derived dependencies, Stores, and React consumers.

## Highlights

- Live atom dependency and component consumer graph
- Multiple Store and nested Provider isolation
- Async atom, atomFamily, private atom, and special value support
- Embedded React Flow UI with Dagre layout
- Development-only Vite/Babel automatic instrumentation
- HMR cleanup and production tree-shaking
- React 18/19 compatibility matrix
- Enforced 500-node performance budgets
- Privacy-first value preview and redaction

## Install

The release assets contain npm-compatible tarballs. Until npm registry publishing is
enabled, local `pnpm.overrides` are required so transitive Visualizer packages resolve to
the downloaded files. npm registry publishing will follow after the
`@jotai-visualizer` organization and trusted publisher are configured.

See [Installation](https://github.com/5vermind/jotai-visualizer/blob/v0.1.0/docs/INSTALLATION.md),
[Compatibility](https://github.com/5vermind/jotai-visualizer/blob/v0.1.0/docs/COMPATIBILITY.md),
and [Privacy](https://github.com/5vermind/jotai-visualizer/blob/v0.1.0/docs/PRIVACY.md).

## Known limitations

- Custom-hook-to-component identity propagation is not implemented.
- Jotai 3 and Vite 7/8 are outside the supported range.
- The pending phase of an uncommitted Suspense-only atom cannot be enumerated without
  another subscriber.
- Browser extension and time travel are future work.
